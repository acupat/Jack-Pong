# Square Pong Game

A modern take on the classic Pong game, featuring Square's minimalist design aesthetic and a special ball - Jack Dorsey!

## Features

- Clean, minimalist design inspired by Square's branding
- Smooth gameplay with responsive controls
- Jack Dorsey as the ball (using his face image)
- Score tracking with reset functionality
- Floating square symbols in the background
- Black and white color scheme

## How to Play

1. Use the Up and Down arrow keys to move your paddle (left side)
2. Try to hit the ball (Jack Dorsey) past the computer's paddle
3. Score points when the ball passes the computer's paddle
4. Use the "Reset Score" button to start a new game

## Technical Details

- Built with HTML5 Canvas
- Pure JavaScript implementation
- Responsive design
- Minimal dependencies

## Game Controls

- ↑ (Up Arrow) - Move paddle up
- ↓ (Down Arrow) - Move paddle down
- Reset Score button - Reset the game score
